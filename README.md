# shipo-tax · בקשת שיפוי רבעונית

כלי להכנת הבקשה הרבעונית ל**קרן לשיפוי יצואנים בגין פגיעה בהסכמי סחר**: מעלים את מסמכי המשלוחים, והכלי מפיק:

1. **טבלת אקסל ממולאת** במבנה הגליון שמוגש לקרן (עמודות A–BJ, עד 5 סיווגים זכאים בשורה, נוסחאות לסכומים), עם גליון "ריכוז רבעוני" וגליון "בקרות".
2. **דף סיכום לרשות המסים (PDF)**: טופס הבקשה ממולא ברמת הרבעון, נספח א' עם כל משלוחי הרבעון ונספח ב' עם ריכוז לפי פרט מכס וחודש.
3. אפשרות נוספת: **טופס לכל משלוח** (PDF), כמו הטופס שצורף עד היום לכל תיק משלוח.

## איך עובדים

1. בוחרים שנה ורבעון. אחרי שהמשלוחים נקראים, הכלי מציע את הרבעון לפי תאריכי הטעינה.
2. מעלים קבצים, אחד לכל משלוח: PDF עם רשימון יצוא, שטר מטען, חשבון עסקה (Duty Invoice), רשימת אריזה, הצהרת יבוא אירופית (IM4) והוכחת תשלום המכס. אפשר גם להעלות כל מסמך בקובץ נפרד, והכלי מקבץ את העמודים למשלוחים לפי מספר שטר המטען, מספר החשבון ומספר הצהרת היצוא.
3. לוחצים **"קרא את המסמכים"**. Claude קורא כל עמוד, ואחר כך מרכיב לכל משלוח שורה אחת בטבלה.
4. בודקים את השורות המסומנות ומתקנים בטבלה. כל שינוי מחושב מחדש מיד.
5. מורידים את האקסל ואת דף הסיכום.

אפשר גם לטעון אקסל רבעוני שכבר מולא (למשל של רבעון קודם). הכלי בודק אותו ומפיק ממנו דף סיכום. כדי להמשיך להוסיף מסמכים במהלך הרבעון, שומרים "גיבוי עבודה" (JSON) וטוענים אותו בפעם הבאה.

### איפה הכלי רץ

- **מתוך Claude (claude.ai)**: הכלי פורסם כ-Artifact. הקריאה נעשית בחשבון Claude שלכם, ולא צריך מפתח API.
- **בדפדפן רגיל**: פותחים את `app/index.html` ומזינים מפתח Anthropic API בהגדרות. הקריאה נעשית במודל `claude-opus-5-5`.

## איך כל עמודה ממולאת

| עמודה | מקור |
|---|---|
| מס' הצהרת יצוא | "מספר הצהרה לדיווח מע"מ" (9 ספרות) ברשימון היצוא |
| מס' חשבון עסקה, תאריך, מונח מכר | חשבוניות ה-Duty Invoice של המשלוח (`WT24001234/1/2`) |
| ערך משלוח כולל למכס, משקל נטו | החשבונית הראשונה (‎/1) של המשלוח, כמו באקסל שהוגש. בהגדרות אפשר לעבור לסכום כל החשבוניות |
| ערך יצוא זכאי לשיפוי | שורות החשבונית של המוצרים שחויבו במכס, כנוסחה `=a+b+c` |
| מס' שטר מטען, תאריך טעינה, משקל ברוטו | שטר המטען |
| מס' הצהרת יבוא IM4, תאריך שחרור | ה-MRN בתיבה A (בטבלה מופיעות הספרות המשמעותיות, למשל `12345678`) |
| מדינת יעד, נמל | המדינה והעיר של משרד המכס שגבה את המכס (למשל בלגיה, LIEGE) |
| סיווג 1–5 | כל פריט ב-IM4 שחויב במכס (שורת A00): פרט מכס, תיאור, משקל נטו, ערך למכס, אחוז וסכום |
| אתר / מיקוד גידול | רשימת האריזה (שם הישוב והמיקוד של המגדל) |
| סה"כ סכום שיפוי מבוקש | נוסחה שמסכמת את סכומי המכס של כל הסיווגים |

## בדיקות שהכלי מריץ

- ערך למכס × אחוז המכס שאינו שווה לסכום המכס.
- סכום הסיווגים שאינו תואם לסכום המכס במסמכים ("Report de paiement" או הקצאת התשלום לפי שטר מטען).
- נוסחת סה"כ שלא כוללת את כל הסיווגים, באקסל שנטען.
- אותו תיאור מוצר עם פרט מכס שונה בתוך הרבעון.
- משלוח שתאריך הטעינה שלו מחוץ לרבעון.
- כפילויות של שטר מטען או של הצהרת יצוא.
- שדות חובה חסרים.

## פרטיות

הקבצים לא נשמרים בשום שרת של הכלי. תמונות העמודים נשלחות ל-Claude לקריאה בלבד. הנתונים שנקראו ופרטי החברה נשמרים בדפדפן שלכם, ובגיבוי שאתם מורידים.

המאגר הזה ציבורי. אין להעלות אליו מסמכי משלוחים, אקסלים ממולאים או פרטי חברה.

## פיתוח

```
npm install
npm test
```

- `app/index.html`: הממשק. הוא כתוב בלי `<html>`/`<head>` כי פלטפורמת ה-Artifact עוטפת אותו.
- `app/js/core.js`: מודל הנתונים, בדיקות וריכוז רבעוני (ללא DOM, נבדק ב-Node).
- `app/js/excel.js`: בניית האקסל במבנה התבנית וקריאתו בחזרה.
- `app/js/summary.js`: דף הסיכום והטפסים (HTML → SVG → canvas → PDF).
- `app/js/extract.js`: קריאת המסמכים עם Claude: הנחיות, רינדור עמודים וקיבוץ למשלוחים.
- `tools/build-fonts.mjs`: מטמיע את הגופנים (Assistant, Frank Ruhl Libre, רישיון SIL OFL) ב-`app/js/fonts.js`.

כדי להריץ את הבדיקה מול אקסל אמיתי שנמצא מחוץ למאגר: `SHIPO_TEMPLATE=/path/to/file.xlsx npm test`.
